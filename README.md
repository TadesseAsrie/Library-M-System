# 📚 Library Management System 

A modern, responsive Library Management System built with React.js, Tailwind CSS, and React Router. 

## ✨ Features

### Core Modules
- **Dashboard** – Statistics cards, recent activities, charts, quick actions
- **Books Management** – List, search, filter by category, sort, add/edit/delete books, book details page, pagination
- **Members Management** – List, search, add/edit/delete members, member profile page
- **Borrowing Management** – Borrow/return books, borrow history, due date tracking
- **Categories Management** – CRUD operations for book categories
- **Authors Management** – CRUD operations for authors
- **Reports** – Statistics cards, books by category chart
- **Notifications** – Overdue books alerts, new member notifications
- **User Profile** – Edit profile, change password (UI only), avatar upload
- **Settings** – Dark/light mode toggle, language selector, notification preferences

### UI/UX
- Fully responsive (mobile first)
- Sidebar navigation with collapse on mobile
- Dark/Light theme (persisted in localStorage)
- Toast notifications
- Loading skeletons
- Modal dialogs for forms
- Pagination components
- Breadcrumb navigation
- Professional library-themed design

## 🛠️ Tech Stack

- **React 18** – Functional components + Hooks
- **React Router DOM v6** – Client-side routing
- **Context API** – Global state management (books, members, borrows, authors, categories)
- **Tailwind CSS** – Utility-first styling
- **React Icons** – Icon library
- **Recharts** – Simple bar charts for dashboard & reports
- **UUID** – Generate unique IDs for mock data
